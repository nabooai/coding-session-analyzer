# CSA

**Turn your team's AI coding sessions into shared, usable knowledge.**

CSA captures the coding decisions already buried in Claude Code sessions, extracts evidence-backed facts,
and makes them searchable by exact technical terms, people, projects, and dates.

- Ask why a service uses Postgres instead of SQLite and open the session evidence.
- Find repeated work that should become a team skill.
- Share selected projects without granting access to every private session.

## Start here

1. [Install the server](getting-started.md).
2. [Choose and test a model](models.md).
3. [Connect the readable Claude Code plugin](plugin.md).
4. Finish a new session and verify your [first search](getting-started.md#verify).

CSA is self-hosted. The plugin is disabled when installed, requires browser authorization, redacts common
secret formats locally, and does not backfill old sessions unless you explicitly request it.
